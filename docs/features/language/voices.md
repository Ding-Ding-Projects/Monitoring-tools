# English voice and Cantonese voice

**What they do.** Choose which installed Windows voice the narrator uses for each language. "Automatic" uses the first installed voice for that language. English voices are those tagged `en-*`; Cantonese voices are tagged `zh-HK` or `yue`.

**Default.** Automatic for both.

**Searching.** The voice list has its own search with plain text by default and an anchored regex builder, so long voice lists stay manageable.

**No Cantonese voice?** The page says so plainly and offers "Open Windows speech settings" (`ms-settings:speech`) so you can add one. Until then Cantonese is not spoken.
