# Records and exports

The Records page in the control centre keeps four things together: a log of everything the app has told you, a history of your settings, exports of the app's data, and the release notes.

- [Notification centre](notification-centre.md)
- [Settings history](settings-history.md)
- [Exports](exports.md)
- [Changelog](changelog.md)

Each list has its own search bar with an anchored regex builder, so a search on one list never changes another.
