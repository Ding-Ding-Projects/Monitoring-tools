# Tools

The Tools page in the control centre holds three things that work on your files: a drawing board, publishing a folder to GitHub, and the external editor choice. Long jobs show their progress in a shared progress card.

- [Drawing and annotation](drawing.md)
- [Publishing to GitHub](publishing.md)
- [External editor](external-editor.md)
- [Progress and recovery](progress-recovery.md)

Nothing on this page stores a password or token. Drawings stay on this computer.
