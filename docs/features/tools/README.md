# Tools

The Tools page in the control centre holds three things that work on your files: a drawing board, publishing a folder to GitHub, and the external editor choice. Long jobs show their progress in a shared progress card.

- [Live check](live-check.md): runs the app against real voices, Ollama, the dish catalogue, a forge server and the Minecraft jar.
- [Drawing and annotation](drawing.md)
- [Publishing to GitHub, GitLab and Gitea](publishing.md)
- [External editor](external-editor.md)
- [Progress and recovery](progress-recovery.md)
- [Local history for scripts and the commit message](local-history.md)

Nothing on this page stores a password or token. A token pasted to create a repository on GitLab or Gitea is used once and cleared. Drawings stay on this computer.
