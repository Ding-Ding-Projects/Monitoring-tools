# Search

Every list and page in Monitoring Tools has its own search bar. Plain text is the default; switch a bar to regular expressions with `.*` (Alt+R), match case with `Aa` (Alt+C), and open the regex builder anchored under that bar with **Builder** (Alt+B). `Ctrl+F` jumps to the current page's search.
