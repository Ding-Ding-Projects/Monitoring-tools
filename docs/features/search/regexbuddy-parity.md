# Regex builder parity ledger

Baseline: the official [RegexBuddy manual](https://www.regexbuddy.com/manual.html), family list reviewed 2026-11-04. Product baseline: Monitoring Tools 1.0.8, .NET 8 `System.Text.RegularExpressions`.

Status words: **done** (implemented and rendered from the built app), **partial** (some subfeatures work, the rest are listed), **missing**. Nothing is marked done from source reading alone. A complete per-topic ledger covering every manual topic is still to be written; this family ledger is the first step, not that ledger.

| Family | Status | What works | What is missing |
| --- | --- | --- | --- |
| Construction and syntax | partial | Raw editing; token palette for classes, Unicode properties, subtraction, anchors, named and numbered groups, atomic and non-capturing groups, backreferences, conditionals, quantifiers (greedy and lazy), lookaround, inline options, comments; selection-wrapping insertion; literal escaping; all .NET options | Balancing groups and POSIX classes in the palette; guided editing of an existing token; recursion and subroutines (not supported by .NET, which must be shown as unavailable, not hidden) |
| Replacement construction | partial | Replacement field with group, named group, `$$`, before, after and whole-input tokens; live preview | Separate replacement explanation; replacement conditionals and case conversion (not in .NET; shown as unavailable is still owed) |
| Analysis and exports | partial | Token-by-token explanation with group depth; validation with the engine's own message; backtracking-risk warning | Editable syntax tree, two-way selection between tree and pattern, adjustable detail, analysis export |
| Flavour comparison and conversion | partial | Compare view: the pattern run in the .NET engine modes that exist (backtracking, non-backtracking, ECMAScript, compiled) with support, match count, first difference and time | Other languages' engines are not available in this app; no cross-flavour comparison and no conversion between flavours |
| Testing and data | partial | Match and split; match list with positions; capture table including unmatched groups; empty-match handling; selection in the sample; measured time; sample from the searched list; expected-outcome test cases (should match / should not match) with live pass or fail, saved with Library entries | Line and page scopes, clipboard input, hex view, encoding and line-ending controls for the sample (file input exists only through the Files view) |
| Debugger | partial | Debug view: a separate instrumented backtracking interpreter for a stated subset (literals, `.`, classes, anchors, ``, groups, alternation, greedy and lazy repeats, backreferences) with Prev, Next, Play, highlighted pattern token and text position, 100,000 step limit, and a mandatory agreement check against the .NET engine before a trace is shown | It is not the .NET engine's own trace. Lookaround, atomic groups, conditionals, inline options, Unicode properties, class subtraction, right-to-left, non-backtracking and ECMAScript are reported as unsupported with no trace. Only the first 4,000 characters of the subject; match span is checked, captures are not |
| Benchmark and diagnostics | partial | Static risk detection for nested quantifiers and overlapping alternation; 200 ms timeout reported; Benchmark view: timing on a matching and a non-matching subject, and an input-growth run at 1x to 16x with a plain verdict (linear, faster than linear, or hit the limit), off the UI thread with Cancel | No profiling per token, no comparison of two patterns, no saved benchmark history; timings are short and noisy |
| Code and escaping | partial | C#, PowerShell and Python snippets with options and timeout; Python named-group conversion and stated limits | Editable templates, replace and split snippets, more languages |
| Saved collections and parameters | partial | Named library saved to settings, use, remove, JSON import and export; expected-outcome test lines per entry, included in export and import | Descriptions, parameters with defaults, collection search |
| File and folder GREP | partial | Files view: folder, include and exclude masks, subfolders, binary and size skipping, encoding detection, cancellable search off the UI thread, results grouped by file with line, column and highlighted match, open in editor, CSV export; replace in files with preview, two-key confirmation, timestamped backups, restore of the last run and a report of skipped or failed files | Compiled only so far, not yet driven in the running app. Opens the file, not the line. Decoded text only: no archives, no hex or binary search, no per-file-type settings, no saved grep presets, no results history, no regex-aware file name search. Restore covers only the newest run |
| Multiple regexes and history | partial | Per-bar recent patterns, up to 50; opt-in (default off) storing them across restarts; independent state for every bar | Side-by-side experiments |
| Integration and automation | partial | `MonitoringTools.exe --regex` command line: match listing, replace output, JSON, option letters, exit codes 0, 1 and 2, 200 ms per-match limit, stdin when no file is given. Run from a pipe and checked for exit codes 0, 1 and 2 | No in-place file replace from the command line, no multi-pattern or library-by-name use, no COM or other automation entry. Console attachment when started from a terminal without redirection is implemented but not checked |
| Help, editing, preferences, layout | partial | Tooltips on every token and option, keyboard shortcuts, Esc returns focus | Contextual syntax help pages, configurable layout, builder preferences, localization |
