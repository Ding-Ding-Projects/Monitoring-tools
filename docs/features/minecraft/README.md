# Minecraft

Create, run and look after Java edition servers on this computer, in Docker, or on another machine over SSH, and Bedrock servers on this computer.
Servers the app did not make can be found and adopted.

The **Minecraft servers** page is a server manager: the list of servers on the left, and the chosen server's workspace
on the right with its own sections.
