# Minecraft

Create, run and look after Java edition servers on this computer, in Docker, or on another machine over SSH.

The **Minecraft servers** page is a server manager: the list of servers on the left, and the chosen server's workspace
on the right with its own sections.

| Article | What it covers |
| --- | --- |
| [Minecraft servers](servers.md) | The server list, the header with its state and actions, the four places a server can run |
| [Create a server](create.md) | The six-step guide: version, software, where it runs, resources, world, review and EULA |
| [Overview](overview.md) | Live tiles, the last console lines, players online and what needs attention |
| [Console](console.md) | The live log with filters and search, and the typed command builder |
| [Players](players.md) | Operators, the whitelist, bans and kicks, through the console or the JSON files |
| [Settings](settings.md) | server.properties with explanations, real bounds and when each change applies |
| [Worlds](worlds.md) | Dimensions with size and seed, import, download, reset and replace |
| [World generator](world-generator.md) | Seed, world type, bounded pre-generation, folder or ZIP output |
| [Plugins and mods](plugins.md) | Installed jars with on and off switches, install from a file, the Modrinth catalogue |
| [Backups](backups.md) | Back up now, restore, how many to keep and where |
| [Schedules](schedules.md) | Restarts, backups, messages and update checks on a timetable |

Not applicable: this category has no HTTP API, so it has no Postman collection.
