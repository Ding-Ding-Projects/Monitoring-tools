Clipboard toasts

Every copy, previewed. Hover and it stays.

A toast slides into the corner for three seconds. Point at it and it holds, showing four actions picked for what you copied, with the rest one click away.

  • Markdown renders, links open privately or lose their tracking, JSON pretty-prints, colors convert.
  • File paths get real previews: video frames, PDFs, album art, code, CSV tables, folders and zips.
  • Paths copied with quotes get a one-click Remove quotes.
  • Drag the preview straight out into chat apps, editors or Explorer.
Quick commands

Copy a path. Add a word. Done.

The command runs the moment it lands on the clipboard. Conversions keep the folder and name, and never overwrite anything.

:mp4:gif:webm:mp3:wav :flac:png:jpg:webp:avif:ico:push
  • A folder path converts every compatible file inside it.
  • :push stages, commits with your message template and pushes.
  • Write your own :name commands as batch or PowerShell scripts in the built-in editor.
D:\Footage\clip.mov:mp4clip.mp4 beside it

Internet watch

Not just "no internet". Where, and what to press.

A probe ladder checks the adapter, the IP address, the router, DNS and the open internet, so the dialog can say exactly which one broke. It stays on top until the line is back.

  • One press for ipconfig release, renew and DNS flush.
  • Switch DNS to Google, Cloudflare, Quad9, OpenDNS or your own saved profile.
  • Spots captive portals and opens the sign-in page.
And the rest

Small things that add up.

File tools

Move, copy, delete to the Recycle Bin, batch Base64 and password encryption with AES-256-GCM.

Game mode

On by default. Roblox, Minecraft, League and fullscreen apps keep the screen; popups wait.

Docker aware

Copy a compose file or Dockerfile and get up, down, pull, logs or build, each explained first.

Control centre

Live latency, outage history, an activity feed, clipboard history and every setting in one place.

Runs like a service

Starts at sign-in, restarts itself after a crash, optional elevated mode, uninstall from the tray.

Private by design

History stays in memory. Password manager copies are skipped. No accounts, no telemetry.

Screenshots

Rendered from the real app on every release.

The build runs the app in a screenshot mode on a Windows machine, so these always match the current version.
