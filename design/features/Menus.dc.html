Base64, written beside the file

Drop any file and its Base64 is written next to it as name.ext.base64.txt. Drop that text file and the original comes back beside it with its extension. Nothing is overwritten, every result is checked by a SHA-256 round trip, and each one can be undone.

Panels you can resize and move

Drag the header to move a floating panel and any edge or corner to resize it. On the keyboard, focus the header and use the arrow keys to move it, with Shift to resize. The size and place are kept for each page, with a reset.
