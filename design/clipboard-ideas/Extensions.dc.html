HOW AN EXTENSION PLUGS IN 
extension.json
{
  "id": "ticket-keys",
  "name": "Ticket keys",
  "version": "1.0.0",  "api": 1,
  "detect": [{ "kind": "ticket",
     "pattern": "^[A-Z][A-Z0-9]+-\\d+$" }],
  "actions": [{ "id": "open",
     "label": "Open ticket",
     "for": ["ticket"], "primary": true }],
  "run": "ticket-keys.exe",
  "permissions": ["read-text", "open-links"]
}
in  → {"action":"open","kind":"ticket","text":"ABC-1234"}
out ← {"open":"https://tracker.example/ABC-1234"}

Any language works: the app sends one line of JSON and reads one line back. Extensions live in %LOCALAPPDATA%\MonitoringTools\Extensions. They never see clips from password managers or anything that looks like a secret, and they only get the permissions you allow.
