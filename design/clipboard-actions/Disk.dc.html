Virtual hard disk dialog: VHD or VHDX with the selected files inside

Creates a disk file, mounts it, formats it and puts the selected files in, with the administrator permission step stated up front and every failure leaving nothing behind.

A
Virtual hard disk dialogA separate window. The permission note sits first because it changes what pressing Create does. Create carries the Windows shield mark.

Create virtual hard disk

Copy or move 3 selected items in · 48.2 MB

Administrator rights are needed. Creating and mounting a virtual disk makes Windows ask for permission (consent prompt) when you press Create. The app never answers it.
Disk file
Format
VHDX: up to 64 TB, safer after a power cut. VHD: older tools, up to 2,040 GB.
Type
Starts small and grows up to 64 GB as you add files. Fixed takes the full 64 GB on D: right away.
Contents
Put the 3 selected items in
Move deletes the originals only after every file copied and matched its size, after the two-key confirmation.
Volume
File system
FAT32 is off at 64 GB: Windows formats FAT32 only up to 32 GB, and no file on it may pass 4 GB. exFAT has no permissions. NTFS keeps permissions and compression.
Mount as
Next free letter. Folder mode needs an empty NTFS folder, such as D:\Mounts\Work.
After
When it is done
VHDX · dynamically expanding up to 64 GB · NTFS “Work” · mounts as V: · copies 3 items (48.2 MB)
The file starts at about 50 MB on D:. GPT partition, quick format.
Esc cancels · Ctrl+Enter creates
B
ProgressEach step is named; the copy step shows bytes. Cancel detaches and deletes what was made.
