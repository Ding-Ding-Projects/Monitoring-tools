Install command toast and automatic mode

A copied choco or winget install command shows what would be installed, from where, and whether Windows will ask for permission. Automatic mode is a separate opt-in with strict rules.

G
Settings card: install copied commands automaticallyOpt-in, off by default, with the full safety rules written next to the switch.
Install copied commands automatically
Settings, Clipboard
Install without asking first
Off by default. When on, a plain install command starts after a short delay with a Cancel button.
Turn this on only if you trust everything you copy. Anything on the clipboard that matches the rules to the right will install software.
The two numbers are typed values with steppers. They stay dimmed until the switch is on. Delay 3 to 60 s, packages 1 to 10.
Installed automatically only when
  1. The clipboard is exactly one command: choco install <name> [-y] or winget install --id <id> [-e].
  2. No pipes, &&, ;, redirects, variables or quotes that run code.
  3. Package names use letters, digits, dots, dashes and underscores only.
  4. The default source is used; a custom source is refused.
  5. Windows shows its consent prompt every time for choco. The app never answers, hides or pre-approves it.
  6. Each run is logged in Activity with the exact command.
Refused flags
--source / -s--ignore-checksums--ignore-package-exit-codes--force / -f--params / --package-parameters--install-arguments--override--pre / --prerelease--allow-downgradeany flag not on the allowed list
A refused command still gets a toast that says why, with Copy command. It is never silently ignored.
