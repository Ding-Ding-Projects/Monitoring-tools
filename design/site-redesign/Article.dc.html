Convert media

Copy a file path, add :format on the end, and the converted file appears next to the original with the same name.

4 min readShipped in v1.0.5746 formats

Convert a video

  1. Copy the file's path, for example D:\Footage\clip.mov.
  2. Make the copied text end in :mp4 and copy that.
  3. A toast reports progress, then the result.

An existing file is never overwritten. A number is added instead, and the line above the buttons names the exact file that will be written.

Choose from the full list

Press Convert on the toast of a copied video, audio or picture file. A dialog lists every format the file can become, grouped into Video, Audio, and Pictures and animations.
